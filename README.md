# Discord通知マネージャー (discordNotifyManager)

Windows 11環境でDiscordの通知を常時監視し、一定時間（設定可能: デフォルト3秒）後に通知を自動削除しながら、受信した通知ログをローカルに自動保存する常駐デスクトップツールです。

モダンなダークテーマの管理画面GUI（CustomTkinter）を備えており、通知ログの閲覧・検索・ピン留めや設定変更を直感的に行えます。

---

## 🌟 主な機能

### 1. 🖥️ モダンな管理画面GUI（CustomTkinter）
- **📋 ページネーション付き通知ログ一覧**:
  - Discordから受信した通知をスタイリッシュなカード形式で一覧表示。
  - ページめくり（デフォルト1ページ20件）を採用し、**通知件数が数百〜数千件溜まっても超軽量＆爆速動作**。
- **✂️ 本文の長文制限**:
  - 300文字を超える長文メッセージは末尾を自動省略し、画面のレイアウト崩れや重さを防止。
- **🔍 確定型キーワード検索**:
  - キーワードを入力して「Enterキー」または「🔍 検索」ボタンで高速絞り込み。
- **🏷️ 絞り込みフィルター**:
  - `すべて` / `📌 ピン留め` / `本日` のタブ切り替え。
- **📌 ピン留め（あとで読む）機能**:
  - 大事な通知をワンクリックでピン留め保存。ピン留め通知はログ上限による自動消去から保護されます。
- **🚀 Discordを開く**:
  - 通知カードやフッターからDiscordクライアントを最前面にワンクリック起動。
- **🧹 ログのワンクリック全消去**:
  - 誤操作防止の確認ダイアログ付きで、溜まったログを一括クリア。

### 2. ⚙️ 設定（`config.json`）の一元管理
- **通知自動削除秒数の変更**: 1秒〜30秒の間でスライダー調整可能。
- **1ページあたりの表示件数**: 10件 / 20件 / 50件から選択可能。
- **ログ最大保持件数（FIFO）**: 自由な数値を直接入力可能。上限を超えると古い通知から自動削除（ピン留めは保護）。
- **自動削除の有効 / 一時停止**: スイッチひとつでログ保存のみのモードに切り替え可能。
- **通知ログ保存の有効 / 無効**: スイッチひとつでファイル保存をスキップし、自動削除のみを実行する運用も可能。

### 3. 🖱️ タスクトレイ常駐 ＆ Windowsスタートアップ
- コンソールを閉じた状態でも画面右下のタスクトレイに常駐。
- トレイアイコンの右クリックメニューから「🖥️ 管理画面を開く」「自動削除の一時停止」「スタートアップ自動起動の登録/解除」などが可能。

---

## 🛠️ 環境要件
- **OS**: Windows 11
- **Python**: 3.10 以上
- **Discord**: Windows デスクトップアプリ版（Windowsトースト通知有効）

---

## 📦 インストール方法

```powershell
# 1. 仮想環境の作成と有効化
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 2. 依存パッケージのインストール
pip install -r requirements.txt
```

---

## 🚀 使い方

### バックグラウンド起動（通常利用）
```powershell
pythonw main.py
```
黒いコンソールを出さずにタスクトレイに常駐します。
タスクトレイアイコンを右クリックして **「🖥️ 管理画面（ログ・設定）を開く」** をクリックすると、管理画面が表示されます。

### コンソールログ付き起動（開発・確認用）
```powershell
python main.py
```

---

## 🖱️ タスクトレイメニュー

- **🖥️ 管理画面（ログ・設定）を開く**: CustomTkinterのGUIウィンドウを開きます。
- **自動削除: 有効 / 一時停止中**: クリックで自動削除のON/OFFを切り替えます。
- **通知ログ (JSON) を開く**: 記録された `discord_notifications.json` を直接開きます。
- **保存先フォルダを開く**: ログやスクリプトが配置されているフォルダを開きます。
- **Windows起動時に自動実行**: PC起動時の自動起動をON/OFFします。
- **終了**: アプリを終了します。
