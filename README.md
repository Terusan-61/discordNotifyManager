# Discord通知マネージャー (discordNotifyManager)

Windows 11環境でDiscordの通知を常時監視し、一定時間（デフォルト: 3秒）後に通知を自動削除しながら、受信した通知ログをローカルのJSONファイルに自動保存する常駐デスクトップツールです。

---

## 🌟 主な機能

- **タスクトレイ常駐**:
  - コンソール画面を閉じた状態でも、画面右下のタスクトレイ（インジケーター）に常駐して動作します。
  - トレイアイコンの右クリックメニューから簡単に各種操作が可能です。
- **自動削除 & 一時停止切り替え**:
  - Discordからのトースト通知を受信後、3秒経過すると自動で画面上および通知センターから消去します。
  - トレイメニューからいつでも「自動削除の有効 / 一時停止（ログ保存のみ）」をワンクリックで切り替えられます。
- **Windowsスタートアップ自動起動**:
  - トレイメニューの「Windows起動時に自動実行」にチェックを入れるだけで、PC起動時に自動でバックグラウンド常駐します（管理者権限不要）。
- **通知ログの自動保存**:
  - 受信日時、送信元（チャンネルやユーザー名）、メッセージ本文を `discord_notifications.json` に一覧保存します。
  - トレイメニューから「通知ログを開く」を選ぶと、既定のエディタですぐに閲覧できます。
- **既存通知の保護**:
  - 起動時にすでに溜まっている過去の通知を誤って削除しない安全設計。

---

## 🛠️ 環境要件
- **OS**: Windows 11
- **Python**: 3.10 以上 (Python 3.14 対応確認済み)
- **Discord**: Windows デスクトップアプリ版（Windowsトースト通知有効）

---

## 📦 インストール方法

1. **仮想環境を作成・有効化**:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. **依存ライブラリのインストール**:
   ```powershell
   pip install -r requirements.txt
   ```

---

## 🚀 使い方

### 1. 通常起動（コンソールログ確認用）
```powershell
python main.py
```
コンソールにリアルタイムで通知ログが表示されつつ、タスクトレイにも常駐します。

### 2. バックグラウンド起動（コンソール非表示）
```powershell
pythonw main.py
```
黒いコンソール画面を出さずに、タスクトレイのみに常駐します。

---

## 🖱️ タスクトレイメニュー

画面右下のタスクトレイアイコン（Discordカラーの吹き出しアイコン）を右クリックすると、以下のメニューが表示されます：

- **自動削除: 有効 / 一時停止中**: クリックで自動削除のON/OFFを切り替えます。
- **通知ログ (JSON) を開く**: 記録された `discord_notifications.json` を開きます。
- **保存先フォルダを開く**: ログやスクリプトが配置されているフォルダを開きます。
- **Windows起動時に自動実行**: PC起動時の自動起動をON/OFFします。
- **終了**: 常駐を終了します。

## 📄 保存されるログ形式 (`discord_notifications.json`)

```json
[
  {
    "id": 463200,
    "received_at": "2026-11-03 17:00:00",
    "app_name": "Discord",
    "title": "User (#general, ServerName)",
    "body": "こんにちは！"
  }
]
```
