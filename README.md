# Discord通知マネージャー (discordNotifyManager)

Windows 11環境でDiscordの通知を常時監視し、一定時間（デフォルト: 3秒）後に通知を自動削除しながら、受信した通知ログをローカルのJSONファイルに自動保存するPythonスクリプトです。

---

## 🌟 主な機能
- **自動削除**: Discordからのトースト通知を受信後、指定秒数（デフォルト3秒）経過すると自動で画面上および通知センターから消去します。
- **ログ保存**: 受信日時、送信元（チャンネルやユーザー名）、メッセージ本文を `discord_notifications.json` に一覧保存します。
- **非同期処理**: `asyncio` を使用しているため、3秒の待機中も後続の通知受信を一切ブロックしません。
- **既存通知の保護**: 起動時に既に溜まっている過去の通知を誤って削除しない安全設計。

---

## 🛠️ 環境要件
- **OS**: Windows 11
- **Python**: 3.10 以上 (Python 3.14 対応確認済み)
- **Discord**: Windows デスクトップアプリ版（Windowsトースト通知有効）

---

## 📦 インストール方法

1. **リポジトリのディレクトリで仮想環境を作成・有効化**:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. **依存ライブラリのインストール**:
   ```powershell
   pip install -r requirements.txt
   ```

---

## 🚀 使い方

以下のコマンドで監視を開始します：

```powershell
python main.py
```

## 📄 保存されるログ形式 (`discord_notifications.json`)

```json
[
  {
    "id": 463200,
    "received_at": "2026-11-02 19:05:00",
    "app_name": "Discord",
    "title": "User (#general, ServerName)",
    "body": "こんにちは！"
  }
]
```
